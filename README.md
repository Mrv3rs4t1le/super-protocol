## ⚡ Overview

**Super Protocol** is a fully autonomous desktop studio built to swallow raw `.mp4` video files, transcode them into high-efficiency HEVC assets, slice app icons, patch manifests, and spit out ready-to-install, independently signed live wallpaper APKs compatible with any Android device.

---

## 🚀 Key Features

* **Universal Android Compatibility:** Designed for Android devices that support the underlying video-backed live wallpaper implementation.
* **True Drag-and-Drop Workflow:** Feed any `.mp4` video directly into `pipeline_drop.bat` and let the studio execute the full compilation pipeline.
* **Zero Black Bars (Edge-to-Edge Fill):** Built-in FFmpeg optical scaling (`increase` + `crop`) ensures videos fill high-density 1440x3168 mobile displays edge-to-edge.
* **Automatic Icon Matrix Slicing:** Drop a master `icon.png` into `profiles/`, and the tool automatically scales and injects it across all 5 standard Android mipmap density tiers (`mdpi` through `xxxhdpi`).
* **Independent Package ID Generation:** Every build dynamically generates a unique package identifier (e.g., `com.hayakaz3.wallpaper.<name><timestamp>`), allowing multiple custom wallpapers to coexist side-by-side on your device without update or overwrite prompts.
* **Zero Overwrites:** Intermediate unsigned builds are isolated in `output/`, while final signed APKs are automatically stamped with precise datetimes (`_YYYYMMDD_HHMMSS`) and saved securely inside `output/signed/`.
* **Plug-and-Play Portability:** Unzip it anywhere on your Windows PC, and it anchors its workspace instantly.

## 🛠️ Getting Setup & Operating

### 1. Prerequisites
* **Python 3.x** installed on your system.
* **Java Runtime (JRE / JDK)** installed so Apktool and the APK signer can execute.
* **FFmpeg** installed and added to your Windows System PATH (not bundled in `dependencies/`).

### 2. Installing FFmpeg & Adding to Windows PATH (Required)
Because FFmpeg is not included in this repository, you must install it manually so the studio can transcode videos:

1. **Download FFmpeg:** Visit the official FFmpeg download page at [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html), hover over the **Windows** icon, and select one of the official Windows builds (e.g., `gyan.dev` or `BtbN`) to download a release `.zip` archive (such as `ffmpeg-release-essentials.zip`).
2. **Extract the Archive:** Extract the downloaded `.zip` file to a permanent location on your PC (for example, `C:\ffmpeg`). Inside the extracted folder, locate the `bin` subfolder containing `ffmpeg.exe` (e.g., `C:\ffmpeg\bin`).
3. **Add to Windows PATH:**
   * Press `Win + S`, type **Edit the system environment variables**, and press **Enter**.
   * Click the **Environment Variables...** button near the bottom right.
   * Under **System variables** (or **User variables**), select the **Path** variable and click **Edit...**.
   * Click **New** and paste the full path to your FFmpeg `bin` folder (e.g., `C:\ffmpeg\bin`).
   * Click **OK** on all open dialogs to save your changes.
4. **Verify Installation:** Open a new Command Prompt or PowerShell window and run:
   ```cmd
   ffmpeg -version
   ```
   If version details appear, FFmpeg is ready to use.

### 3. Sourcing Your Base APK (Required)
To keep this repository clean and respect third-party copyrights, the `BASE/` folder containing decompiled APK files is not included.

Before running the studio for the first time:
* Download a video-based Android live wallpaper APK (Oppo Find X7 Ultra light/dark live wallpaper APK — worked best in testing) from a source of your choosing.
* Decompile it using Apktool in your terminal and output it directly as `BASE`:
  ```cmd
  apktool d your_live_wallpaper.apk -o BASE
  ```
  *(Alternatively, decompile it normally and rename the resulting folder to `BASE`.)*
* Place the `BASE/` folder directly inside your `Super Protocol/` directory alongside `studio.py`.

### 4. Running the Studio
* *(Optional)* Drop a square `.png` icon named `icon.png` into `profiles/` if you want a custom app icon.
* Drag and drop any replacement `.mp4` video file directly onto `pipeline_drop.bat`.
* Follow the interactive terminal prompt to enter your custom **Application Label** and **Output APK Name**.
* Retrieve your completed, independently signed APK from `output/signed/` and install it on your Android device!

## 🔧 Troubleshooting
* **`ffmpeg` is not recognized:** Ensure you have downloaded FFmpeg from [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html), added its `bin` folder path to your Windows System Environment Variables (`Path`), and restarted your terminal.
* **`java` is not recognized:** Ensure Java JRE/JDK is installed and added to your system Environment Variables.
* **Apktool build failure:** Verify that your `BASE/` folder was cleanly decoded from a valid live wallpaper APK and contains `AndroidManifest.xml` and `assets/unlocked.mp4`.
* **Video aspect ratio mismatch:** Edit `profiles/reference.json` if you wish to customize the output resolution (width and height) for a specific screen ratio.
